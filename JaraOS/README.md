# JaraOS

Веб-имитация рабочего стола операционной системы в браузере: окна, панель задач, меню Пуск, проводник, терминал, заметки, настройки, экран блокировки и учётные записи JaraID — всё на чистом HTML/CSS/JS, без фреймворков и бэкенда. Данные хранятся локально в `localStorage`.

**Статус: ранняя, сырая версия (0.x).** Публикуется в открытый доступ как есть, для обратной связи и совместной разработки.

> **Отказ от ответственности.** JaraOS — независимый учебный/фан-проект. Внешний вид вдохновлён Windows 11, но проект никак не связан с Microsoft и не претендует на использование её товарных знаков.

## Возможности

- Оконный менеджер: перетаскивание, изменение размера, сворачивание/разворачивание, Snap Layouts (влево/вправо/во весь экран)
- Панель задач и меню Пуск в стиле Windows 11
- Проводник с папками (виртуальная файловая система в `localStorage`)
- Терминал с базовыми командами (`help`, `whoami`, `neofetch`, `mkdir`, `lock`, `license`, `time`, `clear`)
- Заметки с автосохранением
- Настройки: персонализация (акцент, обои), система, обновления (заглушка), учётные записи JaraID, активация лицензии
- Экран блокировки с несколькими JaraID и паролями
- `store.html` — отдельная страница для получения активационного ключа (сейчас бесплатно, ранний доступ)

## Запуск локально

Проект полностью статический, бэкенд не требуется.

```bash
git clone https://github.com/<ВАШ_АККАУНТ>/jaraos.git
cd jaraos
```

Затем просто откройте `index.html` в браузере, либо поднимите локальный сервер (некоторые браузеры ограничивают `localStorage`/скрипты при открытии файла напрямую через `file://`):

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Структура проекта

```
index.html   — рабочий стол JaraOS (окна, таскбар, лок-скрин)
style.css    — все стили
script.js    — вся логика (состояние, окна, терминал, лицензия и т.д.)
store.html   — страница получения лицензионного ключа
```

## Известные ограничения

- Всё состояние (аккаунты, пароли, заметки, файлы) хранится в открытом виде в `localStorage` браузера — это демо-механизм, не предназначен для реальной защиты данных
- Терминал и файловая система — виртуальные, без выполнения настоящего кода
- Лицензионные ключи проверяются алгоритмом контрольной суммы на клиенте — без сервера это не защищает от подделки, годится только для этапа бесплатного раннего доступа
